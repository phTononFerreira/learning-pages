# Exercícios — Nuvem: IaaS, PaaS, SaaS e modelos de implantação

## Q1 (fácil)

Uma prefeitura contrata e-mail corporativo pronto, acessado pelo navegador, sem instalar servidor nem gerenciar sistema operacional. O modelo é:

A) IaaS
B) PaaS
C) SaaS
D) On-premises
E) Colocation

## Q2 (média)

Uma equipe quer publicar uma aplicação web sem gerenciar servidor, sistema operacional, servidor web nem runtime. Qual modelo reduz essa carga?

A) IaaS
B) PaaS
C) SaaS
D) On-premises
E) Backup as a Service

## Q3 (difícil)

Sobre a responsabilidade compartilhada, é correto afirmar que:

A) no SaaS o provedor responde por tudo, inclusive dados e permissões de acesso
B) no IaaS o cliente gerencia SO, aplicação e dados; no SaaS, continua responsável por dados, identidades e configuração de acesso
C) no PaaS o cliente gerencia o sistema operacional e o middleware
D) a responsabilidade é sempre dividida em 50% entre cliente e provedor
E) no IaaS o provedor gerencia a aplicação e o cliente apenas usa

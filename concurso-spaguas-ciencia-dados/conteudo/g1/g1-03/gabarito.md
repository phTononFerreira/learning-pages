# Gabarito — Leitura de gráficos, tabelas e matrizes

## Q1 — E

Três categorias que somam um todo percentual pedem gráfico de setores. Linhas servem para tempo; dispersão, para relação entre variáveis; histograma e boxplot, para distribuição de uma variável. O erro clássico é usar pizza com muitas categorias ou valores quase iguais.

## Q2 — B

32% − 30% = 2 p.p. Com o eixo truncado em 28%, a barra de 32% fica quatro unidades acima da base e a de 30% fica duas — o dobro visual para uma diferença de 2 p.p. Gráfico de barras deve partir do zero. C usa 30 como base (2/30 ≈ 6,7%; o correto é 2/32 = 6,25%); D inverte a comparação; E confunde barras com série temporal.

## Q3 — D

A dispersão indica associação, não direção causal. Municípios maiores tendem a ter mais fiscais e mais autos; o tamanho do município confunde a leitura. Afirmar que contratar fiscais aumenta autos exige desenho que isole essa variável. As demais extrapolam a evidência ou invertem o padrão.

## Flashcards

- Gráfico para tendência ao longo do tempo? — Linha, com intervalo constante no eixo x.
- Barras podem começar acima de zero? — Não. O zero é obrigatório para comparar tamanhos.
- O que a dispersão não prova? — Causalidade. Ela mostra associação entre duas variáveis.

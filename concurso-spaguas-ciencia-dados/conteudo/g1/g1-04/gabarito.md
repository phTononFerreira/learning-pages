# Gabarito — Estatística descritiva para decisão

## Q1 — A

A mediana é 13 dias: com os dados ordenados, é o terceiro valor. A média é 28 dias, puxada pelo processo de 90 dias, que é outlier. Para tempo de processo com casos extremos, a mediana descreve melhor o típico. As demais alternativas repetem valores isolados ou a média inflada.

## Q2 — B

A diferença absoluta é 6 pontos percentuais. O crescimento relativo é 6/40 = 15%. A alternativa A confunde p.p. com porcentagem; C inverte os números; D usa o valor final como taxa; E troca o sinal. São exatamente as trocas que a banca arma.

## Q3 — C

A média simples das médias só valeria com grupos de mesmo tamanho. Ponderando: (100×20 + 300×40) ÷ 400 = 14.000 ÷ 400 = 35 dias. A alternativa A é a armadilha clássica da média de médias; B e D repetem uma regional; E soma as médias sem ponderar.

## Flashcards

- Quando preferir mediana à média? — Com outliers ou distribuição assimétrica, como renda e tempo de processo.
- De 40% para 46%: quantos pontos percentuais? — 6 p.p.; em termos relativos, alta de 15%.
- Como calcular média de grupos de tamanhos diferentes? — Média ponderada pelo tamanho de cada grupo.

Três coisas que você vai saber fazer

Não é sobre “escrever prompts bonitos”. É sobre projetar uma decisão que aguenta produção.

Projetar

Definir taxonomia, fronteiras, prioridade, regras e contrato de saída para um nó de classificação ou extração.

Provar

Montar um golden set (base de teste auditada), ler a matriz de confusão, calcular o intervalo de confiança e distinguir ganho real de ruído.

Operar

Validar a saída, resistir a injection, definir fallback e estimar custo real por mil chamadas.

transparência

O que este material não é

  • Não é um benchmark. O dataset de 150 casos é sintético e curado para ensinar; as predições v1–v4 são autorais, não execuções do Bedrock. Os números servem para comparar decisões, não para prever seu tráfego.
  • Não chama o Bedrock. Nenhuma interação roda inferência em nuvem. Mas os cálculos de métricas, intervalo de confiança, custo e parsing rodam de verdade no navegador.
  • Não é eterno. Preços e limites são de nov/2026. O Nova Lite 1.0 já tem fim de suporte (EOL) sinalizado, por isso isolamos o prompt para facilitar a troca de modelo.
  • Não substitui eval. Nenhum prompt deste curso deve ir para produção sem golden set, validação de saída e fallback.
